# Contribution guidance

Contributions are welcome under the MIT License. Proposed changes should preserve the synthetic-only, offline default; include benign and hostile controls; state evidence limits; and run the documented tests and lab report. Publication of this early prototype does not imply a frozen book release.

Do not submit manuscript text, production assets, personal data, credentials, downloaded exploit code or model weights. Separate policy-control tests from real-model evaluations. Changes to defaults, permissions, data collection, networking or dependencies require explicit review. Report negative results instead of removing inconvenient cases.
